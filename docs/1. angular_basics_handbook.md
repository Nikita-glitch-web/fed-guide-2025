# Angular Basics Handbook — Junior Full-Stack Developer Track

## 🎯 Goal
Master the fundamentals of Angular (v18+) to build scalable SPAs with Signals, Angular Material, and best practices.

---

## 1. Environment Setup
**Tasks:**
- Install Node.js LTS via `fnm` or `nvm`.
- Configure `yarn` as the default package manager.
- Install Angular CLI (`npm install -g @angular/cli`).
- Create a new Angular project with `--standalone` and `--style=scss`.

**Acceptance Criteria:**
- Project builds without errors.
- SCSS and standalone components are used.

**Similar Examples:**
- [Angular Quick Start](https://angular.dev/tools/cli)

---

## 2. Angular Architectural Principles
**Tasks:**
- Understand the difference between Standalone Components and NgModules.
- Create `core/` and `shared/` folders.
- Organize the project using a feature-first structure.

**Acceptance Criteria:**
- `core` contains services and config.
- `shared` contains UI components and utilities.
- Each feature in its own folder with `routes.ts`.

**Examples:**
- [Angular Folder Structure Best Practices](https://angular.dev/style-guide)

---

## 3. Signals vs RxJS
**Tasks:**
- Understand when to use Signals and when to use RxJS.
- Implement a counter with Signals and a list of items from an API using RxJS.

**Acceptance Criteria:**
- Signals are used for local component state.
- RxJS is used for handling HTTP streams.

**Examples:**
- Signals counter → [Angular.dev Signals Guide](https://angular.dev/guide/signals)
- RxJS API fetch → [RxJS from Angular HttpClient](https://angular.dev/guide/http)

---

## 4. Angular Material — Basic Components
**Tasks:**
- Install Angular Material.
- Add a global theme and connect typography.
- Use MatToolbar, MatButton, MatCard on the home page.

**Acceptance Criteria:**
- UI is built entirely with Angular Material.
- Light and dark themes are available.

**Examples:**
- [Angular Material Theming Guide](https://material.angular.io/guide/theming)

## 5. Routing and Navigation
**Tasks:**
- Configure lazy-loaded routes.
- Add a `canActivate` guard for protected pages.
- Add a Material Sidenav with links to pages.

**Acceptance Criteria:**
- Lazy-loaded modules work correctly.
- Accessing a protected route without permissions redirects to login.

**Examples:**
- [Angular Routing](https://angular.dev/guide/router)

## 6. Forms and Validation
**Tasks:**
- Implement a login form using Reactive Forms.
- Add a custom validator (e.g., email).
- Use Angular Material FormField, Input, and Button.

**Acceptance Criteria:**
- The form cannot be submitted with invalid data.
- Validation messages follow Material design.

**Examples:**
- [Reactive Forms](https://angular.dev/guide/reactive-forms)

## 7. HTTP Requests and Interceptors
**Tasks:**
- Implement an interceptor to add an Authorization header.
- Implement an interceptor for global error handling (Material Snackbar).

**Acceptance Criteria:**

**Examples:**

## 8. Optimization and Performance
**Tasks:**

- Add trackBy to *ngFor.
- Use `@defer` for lazy loading heavy elements.

**Acceptance Criteria:**
- No unnecessary component re-renders.
- Lighthouse Performance ≥ 90.

**Examples:**
- [Angular Performance Guide](https://angular.dev/guide/performance)

## 11. Deployment
**Tasks:**
- Build the project with `ng build --configuration production`.
- Compare different hosting options:
  - **Static hosting** (Vercel, Netlify, GitHub Pages).
  - **Custom server** (Nginx, Apache, or any cloud VM).
- Document the pros and cons of each option:
  - Cost.
  - Performance.
  - Ease of setup.
  - Scalability.
- Choose the most suitable option for the project and justify the choice.
- Deploy the `dist/` folder to the selected hosting.
- Configure caching headers for static assets.
- Set up a fallback for SPA routes (`index.html`).

**Acceptance Criteria:**
- A short document (1–2 paragraphs) comparing hosting options is prepared.
- Application is accessible via a public URL.
- Routes work after page reload.
- Assets are cached for performance.

**Examples:**
- [Deploy Angular to Vercel](https://vercel.com/docs/frameworks/angular)
- [Angular Deployment Guide](https://angular.dev/guide/deployment)
